アプリ T.OF... について

問い合わせ

T.OF... のサイトとアプリについての問い合わせは、内容に合わせて次のどちらかから送ってください。個人で作っているので、返事に時間がかかることがあります。

不具合・要望（誰でも読める）

GitHub の Issues に書いてください。GitHub のアカウントがいります。 書いた内容は誰でも読めるので、メールアドレス、お札の記番号など、ほかの人に見せたくないことは書かないでください。

アプリの名前、使っている端末とブラウザ（例: iPhone の Safari）、どうしたら起きるかがあると、直しやすくなります。

個人的なこと・登録の削除（T.OF... だけが読む）

問い合わせフォーム から送ってください。中身は T.OF... だけが読みます。 返事がほしいときは、フォームにメールアドレスを書いてください。返事のためだけに使います。
