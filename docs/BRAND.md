# T.OF... のブランド

## 名前

- 表記は **T.OF...**（大文字。T の後にピリオド 1 つ、最後に半角ピリオド 3 つ）。「T.OF…」（三点リーダー 1 文字）にはしない。
- 会社ではなく、個人の制作レーベル。
- 由来は円周率 3.14... を英語で読んだ頭文字（**T**hree . **O**ne **F**our ...）。ピリオドの位置も 3.14... と同じ。
  円周率のように終わりがなく、ずっと育ち続けて完璧に近づいていく、という意味。
- アプリの中の表記は「**T.OF... のアプリ**」で、ポータル（`/`）へのリンクにする。

### アプリの名前

- **英語か、カタカナの外来語を基本にする**（例: SHUTTLE STOP、DELTA HUE、QUINTILE）。ひらがな・漢字の造語（「いろわ」「かずかくし」のような形）や、日本語の言葉をカタカナにしただけのもの（「ヒトリチガイ」）は使わない。オーナーの希望（2026-09-25）: 日本語の造語はスタイリッシュでなく、かっこよくない。
- 英字の名前は、カタカナの読みを仕様に書く（J-PlatPat の称呼検索に使う）。
- **名前とは別に、`<title>`・ストアのサブタイトル・短い説明には、種類の名前（検索される言葉）を必ず 1 つ以上入れる**（例: 「ROWBREAK — ブロックパズル：置いて消す 8×8」「LONE DECK: Solitaire」）。人は名前ではなく種類の名前で探す（「ソリティア」「暗記カード」）。種類の名前は、検索して上位を大手が独占していないかを確かめてから決める。他人の商標（例: 「脳トレ」）は種類の名前にも使わない。
- 名前そのものに種類の名前を入れるかは自由（入れなくてよい）。ただし、名前だけでは何のアプリか分からないときほど、タイトルでの補いを厚くする。
- すでに公開したアプリの名前は変えない。例外は公開から数日以内（使っている人がほぼいない間）だけで、変えたら DECISIONS.md に書く（URL と保存キーは古いものから引き継ぐ）。

## ロゴ

ファイルは [`logo/`](../logo/)。作り直すときは `python3 tools/make-logo.py`（図形データはこのスクリプトの中にある）。

| ファイル | 用途 |
|---|---|
| `tof-wordmark.svg` / `.png` | 暗い背景の上の文字ロゴ |
| `tof-wordmark-light-bg.svg` / `.png` | 明るい背景の上の文字ロゴ |
| `tof-mark.svg` / `.png` | アイコン（角丸の背景つき） |
| `tof-mark-transparent.svg` | アイコンの図柄だけ |

- 文字はフォントを使わず、四角・円・円環・正多角形で組んである。どこで表示しても同じ形になる。
- T の「.」と F の「...」は字の下にもぐらせる。「...」は右へ行くほど小さくして余韻を出す。
- 点は **四角 → 八角形 → 16 角形 → 円** と辺が増えていく。円周率の桁が増えるほど円が正確な円に近づく、という意味（アルキメデスの近似の考え方）。
- アイコンは「T」と、小さくなりながら丸くなる 3 つの点（四角 → 八角形 → 円）。

## 色

| 名前 | 値 | 用途 |
|---|---|---|
| 背景 | `#0b0c10` | ポータルの背景、アイコンの背景 |
| 面 | `#13151b` / `#1a1d25` | カード、ボタン |
| 文字 | `#eceef3` | ロゴと本文 |
| 補助の文字 | `#9aa0ab` | 説明文 |
| アクセント | `#ffd35c` | ロゴのドット。明るい背景の上では `#e0a800` |

各アプリの色は自由。ポータルのカードには、そのアプリのアイコンの主な色（`apps.js` の `color`）を使う。

## 各アプリのアイコンと共有画像

- アイコンはアプリごとに作る。頭文字だけの仮アイコンのまま公開しない。
- 512 マスで描き、絵柄は中央 80% に収める（そのまま maskable にも使える）。32px に縮めても形が分かるか確かめる。
- SVG で描いて、Chrome（Playwright）で PNG にする。できた画像は必ず目で見て直す。
- 共有画像（`og.png`、1200×630）は、アプリの見た目・アイコンの絵柄・名前・ひとことを入れる。下の隅に小さく「T.OF...」を入れてよい。

## 文章

- 日本語。短い文で、専門用語を避ける。
- アプリの説明は 1〜2 文。「何をするものか」と「どこが面白いか」を書く。
- 名前のあとの「ひとこと」は 15 字前後（例: 「石に点数がついたオセロ」）。
