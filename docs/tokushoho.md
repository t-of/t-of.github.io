# 特定商取引法に基づく表記（下書き）

課金（有料のアイテム、広告を消す など）を始めるときに、ポータルに `tokushoho/` として公開する。投げ銭と広告だけなら要らないことが多い。
**【】の中はオーナーが決める。** 公開する前に、消費者庁の案内と、使う決済サービス（Stripe など）の求める項目を調べ直す。

個人の場合、住所と電話番号は「請求があれば遅滞なく開示する」と書いて、ページには出さない形にできることがある（条件がある。始めるときに確かめる）。

---

| 項目 | 内容 |
|---|---|
| 販売事業者 | 【氏名（屋号 T.OF... と並べて書く）】 |
| 運営責任者 | 【氏名】 |
| 所在地 | 【住所、または「請求があった場合、遅滞なく開示します」】 |
| 電話番号 | 【番号、または「請求があった場合、遅滞なく開示します」】 |
| メールアドレス | 【問い合わせ用のアドレス】 |
| 販売価格 | 各アプリの購入画面に表示する価格（税込） |
| 商品代金以外に必要な料金 | インターネットの接続料金・通信料金は、お客様の負担となります |
| 支払方法 | 【例: クレジットカード（Stripe）】 |
| 支払時期 | 購入の手続きが済んだとき |
| 引き渡しの時期 | 決済が済んだあと、すぐに使えます |
| 返品・キャンセル | デジタルの商品のため、購入後の返品・キャンセルは受け付けません。正しく動かない場合は、上の連絡先へお知らせください |
| 動作環境 | 最新版の Chrome・Safari・Edge・Firefox（スマホ・パソコン） |
