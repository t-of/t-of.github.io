# これから

T.OF... をこの先どうしていきたいか。オーナーの話をディレクターがまとめる。企画や優先順位に迷ったらここを見る。
書き換えたら、下の「更新」に日付を足す。

## 目指すもの

- 作ったゲームとアプリで収益を得る。ゆくゆくはモバイルアプリとして出す。
- アイデアは、課金してもらえるものか、使う時間・回数が多く広告が効くものを優先する（2026-09-25 オーナー）。形はゲームでも Web ツールでもよい。
- T.OF... を、いくつもの部署がある一つの組織にする。今はアプリ開発だけだが、そこに SNS 運用などの部署を足していく。

## やりたいこと

- **普通のサイトとして公開する**: 今は GitHub の URL（`t-of.github.io`）で出しているのを、独自のドメインで出す。
- **広告を入れる**
- **課金の仕組みを入れる**
- **部署を増やす**: 今のメンバー（企画・デザイン・実装・品質・リリース）は「アプリ開発部」とし、その横に「SNS 運用部」などを置く。スタジオの画面にも部署ごとに出す。

## 今の決まりとの違い

- 今は「独自ドメインは取らない（無料の範囲でやる）」と決めている（DECISIONS.md 2026-09-24）。移るときは、決め直して DECISIONS.md に書く。
- ドメイン・広告・課金は、どれもお金やアカウント・外部サービスが関わるので、進めるたびにオーナーが決める。
- 今のボード（docs/board.json）とスタジオは、アプリ開発の段階（企画 → 公開）を前提にしている。部署を足すときは、部署ごとの仕事を載せられるように作り直す。
- SNS に投稿するのは外に出る操作で、アカウントも要る。投稿の前にはオーナーが確認する。
- 収益化に備えて、企画のたびに権利を調べ、「作る（収益化できる）」かどうかを選んでいる（RULES §1「権利」）。
