# スタジオの依頼文を作る

引数はオーナーの要望（「部屋を 3D の俯瞰にしたい」「書類じゃなくて紙飛行機を飛ばして」など）。

1. [studio/HANDOFF.md](../../../studio/HANDOFF.md) を読み、冒頭の「この資料を受け取った AI へ」に従う。
2. 資料が古くないか確かめる: `git log -1 --format=%ci -- studio/HANDOFF.md` と `git log -1 --format=%ci -- studio/`、`git status studio/` を比べ、資料より新しい変更があれば差分を読み、依頼に関わる所だけ資料を直してから進める。
3. 要望で決めきれない所（どの画面か、色・速さ、今の動きを残すか）は AskUserQuestion で 1〜3 個だけ聞く。ふつうに決められる所は決めて、依頼文に「こう決めた」と書く。
4. 依頼文を 1 つのコードブロックで返す。渡す相手が決まっていなければ「本部の engineer に頼む」「外の AI に HANDOFF.md と一緒に貼る」のどちらにも使える形にする（ファイルの場所は本部からの相対パス）。
5. `.audit/studio-prompt-<日付>.md` にも保存し、場所を伝える。engineer に頼むかどうかはオーナーに聞く（頼むなら board にタスクを足す）。
